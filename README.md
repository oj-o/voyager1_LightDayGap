# 🌌 Light-Day Gap — 300-Second Fulldome Film

![Artwork Status](https://img.shields.io/badge/ARTWORK-5--MIN--FULLDOME-00f0ff?style=for-the-badge)
![License](https://img.shields.io/badge/LICENSE-MIT-yellow?style=for-the-badge)

An abstract audiovisual film for planetarium dome projection, inspired by the Hankyoreh article [**"Voyager 1 reaches 1 Light-Day distance after 49 years"**](https://www.hani.co.kr/arti/science/science_general/1269765.html).

**핵심 문장: "내가 지금 보고 있는 것도 이미 늦게 도착한 것이다."**

---

## v3에서 바뀐 것 — 돔 상영용 전면 재설계

이전 버전(마우스/터치로 반응하는 평면 화면용 웹 인터랙션)을 **조작이 전혀 없는 돔 영상**으로 다시 설계했다.

- **컨트롤 전부 제거**: PAUSE/PLAY, SOUND, TIME, EXPORT 버튼과 하단 툴바를 완전히 없앴다. 화면에는 작품 자체만 있다. 관람객은 아무것도 조작하지 않는다.
- **포인터/시선 인터랙션 제거**: 돔에서 수동 재생되는 영상이므로 마우스·터치 기반 "시선 지연 반응" 로직은 의미가 없어 삭제했다. 대신 모든 변화는 내부 이벤트 스케줄러와 진화형 노이즈만으로 자율적으로 발생한다.
- **정사각형 어안(fisheye) 프레임**: 캔버스를 창의 짧은 변에 맞춘 정사각형으로 렌더링하고, 모든 천체를 (방위각, 천정으로부터의 각도) 구면 좌표로 배치한 뒤 등거리(equidistant) 어안 투영으로 화면에 투사한다. 프레임 중심 = 천정(dome center), 프레임 가장자리 원 = 지평선. 이는 실제 풀돔(fulldome) 상영 시스템이 요구하는 표준 마스터 포맷과 동일한 방식으로, **돔의 전체 공간(전천)을 그대로 활용**한다. 원 바깥은 항상 검정이다.
- **태양계 확장**: 태양(시간이 지날수록 실제 거리 증가에 맞춰 계속 작아짐), 수성~해왕성까지 7개 행성(목성·토성은 보이저 1호가 실제로 근접 통과한 지점에서 크게 부각되고, 나머지는 배경 천체로만 스쳐 지나간다), 그리고 매번 다른 경로로 화면을 가로지르는 혜성 여러 개를 추가했다.
- **카메라 → 돔 회전**: 평면 카메라의 줌/팬/회전 대신, 전천 자체가 아주 느리게 방위각으로 회전하고("돔 회전"), 이벤트 시점에 짧게 빨라지는 방식으로 시점 변화를 만든다.
- **타임라인 재구성 (총 300초, 4분 과거~현재 + 1분 미래)**:

  | 구간 | 내용 |
  |---|---|
  | 0–20s | 지구 발사 (`EARTH` 자막), 태양이 화면 중심 가까이 크고 밝게 |
  | 20–60s | 목성 근접 통과 (`JUPITER` 자막, 줄무늬 표현) — 실제 1979년 사건 |
  | 60–100s | 토성 근접 통과 (`SATURN` 자막, 고리 표현) — 실제 1980년 사건 |
  | 100–160s | 태양계 바깥 행성들이 배경으로 스쳐 지나가며 점점 멀어짐, 혜성 통과 |
  | 160–215s | 헬리오포즈 통과 암시 (실제 2012년, 성간 우주 진입) |
  | 215–240s | 현재: `NOW`, `23:46:00`(편도 신호 지연), `VOYAGER 1` 자막 |
  | 240–300s | **예측된 미래**: 태양계 잔상이 사라지고 하늘이 성겨지며, 보이저는 돔 가장자리 쪽으로 계속 멀어진다. 마지막에 아주 희미한 점 하나가 나타나는데, 이는 약 4만 년 뒤 보이저 1호가 근접하게 될 것으로 추정되는 별(글리제 445, Gliese 445)을 암시하는 시각적 은유다. 실제 과학적 예측을 문장으로 설명하지 않고 점 하나로만 암시한다. |

- **은닉 Export**: 화면에는 어떤 버튼도 없지만, `E` 키를 누르면(제작자용) `MediaRecorder`로 300초 전체를 캔버스+오디오 그대로 `.webm`으로 녹화한다. `M` 키는 음소거 토글이다. 둘 다 관람 경험에는 노출되지 않는 제작 편의 기능이며 화면에 아무 표시도 하지 않는다.

## 실제 Voyager 1 정보 (2026년 기준, 이 작품이 참조한 수치)

- 지구 기준 약 **23시간 46분**의 편도 빛/전파 지연 상태.
- **2026년 11월 18일경** 지구로부터 1광일(light-day) 거리에 도달할 예정.
- **2026년 4월** 전력 절약을 위해 LECP(저에너지 하전입자) 장비가 종료됨.
- 실제로 근접 통과(flyby)한 행성은 **목성(1979)과 토성(1980)뿐**이다. 천왕성·해왕성은 보이저 2호의 경로이며, 이 작품에서는 배경 태양계 천체로만 등장하고 "방문했다"고 표현하지 않는다.
- 약 **4만 년 후** 보이저 1호는 별 **글리제 445(Gliese 445)**에 약 1.6광년 거리까지 접근할 것으로 추정된다 — 마지막 1분의 "미래" 구간이 암시하는 사건이다.

## 아키텍처 요약

- **글로벌 클록**: `const DURATION = 300000; let elapsed = 0;` — 모듈로 반복 없이 한 번만 0→300초로 진행되고, 끝나면 그 상태에서 약 12초에 걸쳐 서서히 어두워진다(재시작하지 않음).
- **돔 좌표계**: `toScreen(azimuth, elevFromZenith)` 하나가 모든 천체(별/행성/혜성/보이저/태양)의 화면 위치를 계산한다. 카메라가 아니라 좌표계 자체가 전천이다.
- **커브 + 진화형 노이즈**: 태양 크기, 보이저의 바깥쪽 이동량, 별 밀도, 화면 왜곡량, 신호 지연량, 화성 긴장도, 돔 회전 속도, "숨쉬기"(전체 스케일 미세 변화)가 모두 0~300초 곡선 위에 계속 드리프트하는 노이즈를 얹어 계산된다.
- **입자/별 시스템**: 최대 1000개, 각자 독립된 수명·밝기·깜빡임을 가지며 생성·소멸을 반복한다(빈도가 별개로 계속 변함).
- **행성**: 목성·토성은 근접 통과 구간에서 크기와 위치가 화면 중심 쪽으로 부각되고, 나머지는 항상 배경에서 느리게 공전한다.
- **혜성**: 이벤트 스케줄러가 트리거할 때마다 매번 다른 경로로 한 번씩 생성되는 꼬리 달린 궤적.
- **사운드**: EARTH(느린 드론)·VOYAGER(더 느린 서브 드론)·LIGHT(고역 셔머 클릭)·SIGNAL(이벤트성 펄스)·DELAY(이전 소리를 몇 초 뒤에 낮은 음량으로 재생) 5개 레이어가 하나의 진화하는 화성(`evolvingScale()`)을 공유해 고정된 코드 진행이 없다.
- **화면 왜곡**: wave(파동)/chroma(색수차 근사)/pixel(픽셀화)를 0.5~3초짜리 사건으로 사용하고, 왜곡 후에는 항상 돔 원형 마스크로 다시 잘라낸다.
- **이벤트 스케줄러**: 20개 내외의 "한 번만 발생하는" 사건(발사, 목성/토성 통과, 혜성, 헬리오포즈, 현재, 미래 진입 등)을 실행마다 ±15% 지터를 준 시각에 배치했다. 한 번 발생한 이벤트는 다시 발생하지 않는다.

## 알려진 단순화

- 실제 fulldome 렌더 파이프라인(예: Dome Master warping 소프트웨어, 프로젝터 블렌딩)과의 통합은 다루지 않는다. 이 코드는 표준 정사각형 어안 마스터 프레임을 생성할 뿐이며, 실제 돔 상영관에 맞는 최종 워핑/블렌딩은 해당 돔의 재생 시스템(예: Uniview, Digistar, Sciss 등)에서 처리해야 한다.
- 어안 투영은 단순 등거리(azimuthal equidistant) 방식이며, 특정 돔 하드웨어의 정확한 렌즈 보정을 반영하지 않는다.
- 행성의 궤도/크기/속도는 과학적으로 정확한 축척이 아니라 서사(발사 → 목성 → 토성 → 성간 진입 → 현재 → 미래)를 전달하기 위한 연출이다.

## 재생 / 녹화

- 그냥 `index.html`을 열면 자동으로 재생된다. 조작할 것이 없다.
- 오디오는 브라우저 정책상 첫 클릭/키 입력 이후에 들리기 시작한다(별도 안내 문구 없음).
- 돔 마스터 영상 파일이 필요하면 재생 중 **E 키**를 누른다 — 처음부터 정확히 300초를 그대로 녹화해 `.webm`으로 저장한다. **M 키**는 음소거 토글이다. 둘 다 화면에 표시되지 않는 제작자 전용 단축키다.
