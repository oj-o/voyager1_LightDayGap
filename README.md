# VOYAGER 1 — LIGHT DAY GAP
## 하루 늦게 도착하는 우리 (보이저 1호의 시선)

> *"칠흑의 심연 속에서, 어제의 지구가 보낸 신호가 내 차가운 안테나에 닿았다.*  
> *내가 보는 당신들은 언제나 어제의 모습이고, 내가 보낸 오늘 역시 내일의 당신들에게 닿을 것이다."*

보이저 1호(Voyager 1)와 지구 사이의 1광일(1 Light-Day, 약 259억 km) 광행시간 간극과 2026년 11월 18일 통과 사건을 다루는 **4K UHD 천체투영관 돔 스크린(Fulldome 180°) 및 시네마틱 미디어아트 프로젝트**입니다.

- **규격**: **225초 (3분 45초)**, 30fps, 총 **6,750프레임** (0000~6749), 48kHz 스테레오 사운드, 형식 **MP4 (H.264 / AAC)**.
- **화질**:
  - **4K UHD 와이드**: 3840×2160 (16:9 Cinematic UHD).
  - **4K Fulldome 돔 스크린**: 3840×3840 / 2160×2160 (1:1 원형 어안 Domemaster, 천정 Zenith 중심, 지평선 Horizon 림 마스크).
- **시작 화면 (Intro Screen)**:
  - 영상 도입부(S00: 00:00~00:15) 및 웹 시작 화면에 **작품 설명 타이틀 카드** 탑재.
- **연출 관점**: 보이저 1호의 1인칭 독백과 가상 시선으로 각색, 영화적 스토리텔링, 직관적이고 간결한 핵심 텍스트 배치.
- **제작 명세서**: [`docs/film_spec.md`](docs/film_spec.md).

## 작품 해설 및 비평: 빛의 하루, 지연된 존재론
### Curatorial Essay & Critical Review

#### 1. 돔 스크린에 새겨진 1광일의 고독
2026년 11월 18일, 인류가 우주로 쏘아 올린 가장 먼 사물이자 최초의 성간 탐사선인 **보이저 1호(Voyager 1)**는 지구로부터 정확히 **1광일(Light-Day, 약 259억 킬로미터 / 173.14 AU)** 떨어진 지점을 통과합니다. 빛조차 편도로 꼬박 24시간, 왕복으로 이틀(48시간)이 걸리는 심연입니다.

본 프로젝트는 천체투영관 돔 스크린(Fulldome) 화면 전체를 180도 반구형 심연으로 전환하여, 관객이 객석에서 천정을 올려다볼 때 스스로가 성간 공간에 홀로 떠 있는 보이저 1호의 몸체와 시선이 되도록 연출했습니다. 4K UHD 초고화질과 MP4 포맷을 기반으로, 과도한 기술적 수식을 걷어내고 영화처럼 이어지는 1인칭 독백과 직관적인 텍스트만으로 우주적 시공간의 어긋남을 감각하도록 각색되었습니다.

#### 2. 꺼진 눈과 기억 속의 창백한 푸른 점
보이저 1호의 광학 카메라는 1990년 2월 14일, 칼 세이건의 헌신으로 이루어진 역사적인 ‘창백한 푸른 점(Pale Blue Dot)’ 촬영을 끝으로 전력 절약을 위해 영구히 차단되었습니다. 

따라서 1광일 거리에서 보이저가 마주하는 지구의 모습은 센서 실사가 아니라, **NASA JPL Horizons의 정밀 궤도역학 벡터와 빛의 지연 방정식을 역산하여 구축한 ‘계산된 가상의 시선(Calculated Virtual Gaze)’**입니다. 0.1015초각에 불과한 극미세 점광원으로 깜박이는 지구는, 시각적 스펙터클을 거두어내고 남은 진실의 침묵입니다.

#### 3. 원자의 맥박: 어제의 당신들에게 띄우는 오늘의 안부
영하 200도를 밑도는 절대 영도의 어둠 속에서 20와트 남짓의 미약한 전파를 지구로 쏘아 올리는 힘은, 탐사선 심장에 실린 **플루토늄-238(Pu-238) 원자핵의 미세한 붕괴열(RTG)**입니다.

우리는 같은 물리 법칙의 우주에 존재하지만, 서로의 ‘현재’를 영원히 동시에 공유할 수 없습니다. 보이저가 보낸 신호가 지구에 도착할 때, 그곳의 우리는 이미 하루를 더 살아낸 뒤입니다. 이 작품은 타자와 연결된다는 것이 그의 현재를 소유하는 것이 아니라, 그가 지나온 과거의 흔적을 경청하고 침묵을 품어 안는 일임을 보여줍니다.

## 4. 실행 및 렌더링 방법

### 4.1 의존성 설치
Python 3.10+ 환경 및 `uv`를 사용합니다.

```bash
uv sync
```

### 4.2 오디오 합성 (48kHz 스테레오 WAV, 225초)
```bash
uv run python src/audio.py
```
`output/audio/mix.wav`에 225초 분량(10,800,000 샘플)의 마스터 사운드가 생성됩니다.

### 4.3 4K 스냅샷 출력 (S00~S09 10개 장면)
```bash
# 4K UHD (3840×2160) 스냅샷 출력
uv run python src/render.py --snapshots

# 4K Fulldome (3840×3840) 돔 스크린 스냅샷 출력
uv run python src/render.py --snapshots --dome
```
`output/snapshots/`에 S00 시작 화면을 포함한 고화질 4K 이미지가 저장됩니다.

### 4.4 4K MP4 비디오 렌더링 (225초 / 3분 45초)
```bash
# 4K UHD 시네마틱 비디오 (3840×2160, H.264/AAC MP4 기본 출력)
uv run python src/render.py --video

# 4K Fulldome 돔 스크린 최종본 (3840×3840 Domemaster 1:1, MP4)
uv run python src/render.py --video --dome

# 빠른 확인용 1080p FHD 렌더링
uv run python src/render.py --video --fhd
```

### 4.5 브라우저 인터랙티브 시안 실행
```bash
npx -y serve .
```
1. 브라우저에서 `http://localhost:3000` 접속 시 **시작 화면(작품 설명 타이틀 카드)**이 나타납니다.
2. **`▶ 4K 감상 시작`** 버튼으로 영상을 즉시 감상할 수 있습니다.
3. 하단 도크의 **`● 4K 녹화`** 버튼과 형식 선택(`MP4` / `WebM`)으로 브라우저에서 화면을 직접 비디오 파일로 다운로드할 수 있습니다.
